# Synthetic-data Specification

> Generated by openlore v1.0.0 on 2026-08-06 07:33

## Purpose

Provides a multi-degree-of-freedom (MDOF) dynamic model of high-speed elevator longitudinal
vibration, assembling substructure mass/stiffness/damping matrices and deriving state-space and
modal properties for reuse/reproduction of the article's analysis.
