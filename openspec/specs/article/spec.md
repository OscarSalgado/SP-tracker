### ElevatorMDOFModel

> `articles\2026-08-02-longitudinal-vibration-elevators\src\elevator_model.py`

Multi-degree-of-freedom (MDOF) dynamic model representing the longitudinal vibration behavior of a
high-speed elevator system, assembled from mechanical substructures (traction machine, car/cabin,
counterweight, ropes).

**Properties:**

| Name | Type | Description |
|------|------|-------------|
| params | dict | Elevator system parameters: masses, stiffnesses, and damping coefficients |
| M | np.ndarray (n_dof x n_dof) | Assembled global mass matrix |
| K | np.ndarray (n_dof x n_dof) | Assembled global stiffness matrix |
| C | np.ndarray (n_dof x n_dof) | Assembled global damping matrix |
