# Validation Specification

> Generated by openlore v1.0.0 on 2026-08-06 07:33

## Purpose

Enforces CONSTITUTION.md structural requirements for an article directory: required files, absence
of source PDFs, presence of reuse code or justified absence, and taxonomy-compliant metadata.

## Requirements

## Sub-components

> `ArticleStructureValidator` is an orchestrator. Each sub-component below implements one logical block.

### Sub-component: RequiredFilesCheck

> Implements: `check_required_files`

Verifies that the article directory contains all files mandated by CONSTITUTION.md.

#### Requirement: VerifyMandatoryFilesPresent

The system SHALL the function shall scan the article directory and must report an error for every required file that is missing.

#### Scenario: AllRequiredFilesPresent
- **GIVEN** an article_dir containing every file required by CONSTITUTION.md
- **WHEN** check_required_files is called
- **THEN** the returned list SHALL be empty

#### Scenario: MissingMetadataFile
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** an article_dir missing metadata.yaml
- **WHEN** check_required_files is called
- **THEN** the returned list MUST contain an error identifying metadata.yaml as missing

### Sub-component: SourcePdfAbsenceCheck

> Implements: `check_no_source_pdfs`

Ensures no copyrighted source PDF files have been committed inside the article directory.

#### Requirement: DetectCommittedPdfs

The system SHALL the function shall recursively search article_dir for pdf files and must report each one found as a violation.

#### Scenario: NoPDFsPresent
- **GIVEN** an article_dir with no .pdf files anywhere in its tree
- **WHEN** check_no_source_pdfs is called
- **THEN** the returned list SHALL be empty

#### Scenario: PDFCommitted
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** an article_dir containing a file article.pdf
- **WHEN** check_no_source_pdfs is called
- **THEN** the returned list MUST include an error referencing the relative path of article.pdf

### Sub-component: ReuseCodeFeasibilityCheck

> Implements: `check_src_or_not_feasible`

Confirms that reuse code exists under src/ or that its infeasibility has been explicitly justified.

#### Requirement: VerifySrcOrJustification

The system SHALL the function shall check for a src/ directory with content and, if absent, must verify a documented not-feasible justification exists; it shall return errors and a feasibility flag accordingly.

#### Scenario: SrcDirectoryPresent
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** an article_dir with a non-empty src/ directory
- **WHEN** check_src_or_not_feasible is called
- **THEN** the function SHALL return an empty error list and a truthy flag

#### Scenario: NoSrcAndNoJustification
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** an article_dir lacking src/ and lacking a not-feasible justification
- **WHEN** check_src_or_not_feasible is called
- **THEN** the function MUST return an error explaining the missing justification and a falsy flag

### Sub-component: MetadataTaxonomyCheck

> Implements: `check_metadata`

Validates the article metadata file structure and that its keywords conform to the taxonomy.

#### Requirement: ValidateMetadataStructure

The system SHALL the function shall load metadata.yaml and must report an error if the file is missing, malformed, or lacks required fields.

#### Scenario: MissingMetadataFile
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** an article_dir with no metadata.yaml
- **WHEN** check_metadata is called
- **THEN** the returned list MUST contain an error stating metadata.yaml is missing

#### Requirement: ValidateKeywordsAgainstTaxonomy

The system SHALL the function shall compare metadata keywords against taxonomy_keywords and must report any keyword not present in the taxonomy.

#### Scenario: UnknownKeywordUsed
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** metadata.yaml declaring keyword 'quantum-foo' not in taxonomy_keywords
- **WHEN** check_metadata is called
- **THEN** the returned list MUST include an error naming 'quantum-foo' as an unrecognized keyword

#### Scenario: AllKeywordsValid
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** metadata.yaml whose keywords are all subset of taxonomy_keywords
- **WHEN** check_metadata is called
- **THEN** the returned list SHALL be empty

### Sub-component: RuffLintCheck

> Implements: `check_ruff`

Runs the ruff linter against the src directory and reports any lint violations.

#### Requirement: RunRuffAndCollectErrors

The system SHALL the function shall invoke ruff against src_dir and must translate a non-zero exit status into descriptive error entries.

#### Scenario: CleanCode
- **GIVEN** a src_dir whose code passes ruff with no violations
- **WHEN** check_ruff is called
- **THEN** the returned list SHALL be empty

#### Scenario: LintViolationsFound
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** a src_dir containing a file with a ruff violation
- **WHEN** check_ruff is called
- **THEN** the returned list MUST contain an error describing the ruff failure output

### Sub-component: TestsCoverageCheck

> Implements: `check_tests_and_coverage`

Runs the test suite for the article's src code and enforces the 100% coverage requirement when tests exist.

#### Requirement: RunTestsWhenPresent

The system SHALL the function shall detect a tests directory and, if present, must execute the test suite with coverage measurement.

#### Scenario: NoTestsDirectory
- **GIVEN** an article_dir with no tests/ subdirectory
- **WHEN** check_tests_and_coverage is called
- **THEN** the returned list SHALL be empty since coverage is not required without tests

#### Requirement: EnforceFullCoverage

The system SHALL when tests exist, the function must report an error if measured coverage is below 100%.

#### Scenario: CoverageBelow100%
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** a tests/ directory whose suite runs but covers only 87% of src/
- **WHEN** check_tests_and_coverage is called
- **THEN** the returned list MUST include an error stating coverage is below 100%

#### Scenario: FullCoverageAchieved
- **GIVEN** a tests/ directory whose suite covers 100% of src/
- **WHEN** check_tests_and_coverage is called
- **THEN** the returned list SHALL be empty

### Sub-component: NotebookExecutionCheck

Confirms the article's reproduction notebook executes end-to-end without errors.

#### Requirement: ExecuteNotebookAndCaptureErrors

#### Scenario: NotebookMissing

- **WHEN** check_notebook_executes is called
- **THEN** the returned list MUST contain an error stating the notebook is missing

#### Scenario: NotebookExecutesCleanly
- **GIVEN** a valid notebook at notebook_path with no runtime errors
- **WHEN** check_notebook_executes is called
- **THEN** the returned list SHALL be empty

#### Scenario: NotebookRaisesDuringExecution
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** a notebook at notebook_path whose cell raises an exception
- **WHEN** check_notebook_executes is called
- **THEN** the returned list MUST include an error describing the execution failure

### Sub-component: ArticleDirExistenceCheck

> Implements: `article_dir.is_dir`

Confirms the given path refers to an existing directory before running validations against it.

#### Requirement: VerifyDirectoryExists

The system SHALL the function shall check whether article_dir exists and is a directory before proceeding with validation.

#### Scenario: PathIsADirectory
- **GIVEN** article_dir points to an existing directory
- **WHEN** article_dir.is_dir is called
- **THEN** the function SHALL return True

#### Scenario: PathDoesNotExist
- **GIVEN** article_dir points to a nonexistent path
- **WHEN** article_dir.is_dir is called
- **THEN** the function SHALL return False

> Implements: `find_changed_article_dirs`

Determines which article directories were modified in the current change set for targeted validation.

#### Requirement: DiscoverChangedDirsFromVcs

#### Scenario: ChangesWithinOneArticle

- **WHEN** find_changed_article_dirs is called with repo_root
- **THEN** the returned list SHALL contain exactly the Path for articles/foo

#### Scenario: NoChangesUnderArticles/

- **WHEN** find_changed_article_dirs is called with repo_root

### Sub-component: TaxonomyKeywordLoader

> Implements: `load_taxonomy_keywords`

Loads the canonical set of allowed keywords from taxonomy.yaml for use in metadata validation.

#### Requirement: ParseTaxonomyKeywords

The system SHALL the function shall read and parse taxonomy_path as yaml and must return the set of all defined keyword strings.

#### Scenario: ValidTaxonomyFile
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** a taxonomy.yaml defining keywords ['nlp', 'robotics']
- **WHEN** load_taxonomy_keywords is called
- **THEN** the returned set SHALL equal {'nlp', 'robotics'}

### Sub-component: ArticleValidationOrchestration

> Implements: `validate_article`

Runs the full set of structural and quality checks against a single article directory and aggregates their errors.

#### Requirement: AggregateAllChecks

The system SHALL the function must invoke check_required_files, check_no_source_pdfs, check_src_or_not_feasible, check_metadata, check_ruff, check_tests_and_coverage, and check_notebook_executes in sequence and shall combine all reported errors into a single list.

#### Scenario: FullyCompliantArticle
- **GIVEN** an article_dir that passes every individual check
- **WHEN** validate_article is called
- **THEN** the returned list SHALL be empty

#### Scenario: MultipleViolations
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** an article_dir missing a required file and containing a source PDF
- **WHEN** validate_article is called
- **THEN** the returned list MUST contain errors from both check_required_files and check_no_source_pdfs

#### Requirement: SkipNonexistentDirectory

The system SHALL the function shall verify article_dir.is_dir before running checks and must return an error immediately if the directory does not exist, without invoking the sub-checks.

#### Scenario: NonexistentArticleDirectory
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** an article_dir path that does not exist on disk
- **WHEN** validate_article is called
- **THEN** the returned list MUST contain a single error stating the directory does not exist
