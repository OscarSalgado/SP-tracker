### Requirement: CLIArticle/Bibliography

The API SHALL support `CLI python scripts/generate_bibliography.py [--check]` to regenerate references.bib from per-article metadata.yaml files found under articles/, or verify (with --check) that the committed bibliography is already up to date.

**Request:**

```json
{
  "check": "boolean (optional CLI flag; if present, compares generated content against existing file instead of writing)"
}
```

**Response:**

```json
{
  "exitCode": "integer (0 = success/up-to-date, 1 = drift detected in --check mode)",
  "sideEffect": "references.bib written to disk (unless --check)"
}
```

#### Scenario: RegenerateBibliographyFromArticleMetadata
- **GIVEN** One or more articles/<slug>/metadata.yaml files exist with required fields (entry_type, title,
authors, year, source_url)
- **WHEN** python scripts/generate_bibliography.py is run without flags
- **THEN** references.bib is overwritten with a BibTeX entry per article, sorted/rendered via
render_bibliography, and the script exits 0

#### Scenario: CheckModeDetectsDrift
- **GIVEN** references.bib on disk does not match what collect_entries()/render_bibliography() would currently
produce
- **WHEN** python scripts/generate_bibliography.py --check is run
- **THEN** the script exits with a non-zero status and does not modify references.bib
- **AND** If references.bib matches the freshly generated content, the script exits 0
