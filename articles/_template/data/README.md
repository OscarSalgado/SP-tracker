# Datos

Esta plantilla no requiere datos externos ni un dataset público: `notebook.ipynb` genera un
pequeño array sintético de entrada (`x`) directamente en la propia celda, suficiente para ilustrar
el uso de `src.square`.

  justificar por qué son representativos del fenómeno del artículo.
